# Resolvendo Algoritmos em Python com o GitHub Copilot

Repositório criado para a entrega do desafio de projeto da Formação GitHub Certification na plataforma **DIO**.

## 🎯 Objetivo
Explorar o uso do **GitHub Copilot** como assistente de inteligência artificial para otimizar o desenvolvimento, gerar sugestões de código e acelerar a resolução de algoritmos em Python.

## 📁 Estrutura do Repositório
- `desafios.py`: Contém a implementação dos algoritmos em Python para manipulação de comandos Git (`git clone`, `git add`, `git branch`, `git checkout`, `git merge`).

## 🤖 Experiência com o GitHub Copilot
Durante a execução dos desafios, a ferramenta auxiliou em:
1. **Autocompletar código:** Sugestões rápidas de formatação de strings e manipulação de variáveis.
2. **Resolução de problemas:** Ajuste na concatenação de comandos sem espaçamentos incorretos.
3. **Documentação:** Criação clara da estrutura de documentação em Markdown.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3
- **Ferramentas:** GitHub, GitHub Copilot, Git
